# Changelog

## 0.1.0 — 2026-10-12

Initial release.

- Per-file port of [`torchquantlib`](../quantorch) (Python/PyTorch) to Rust:
  one Rust module per Python source file, covering options (closed form,
  binomial trees, exotic payoffs, Malliavin MC Greeks), stochastic volatility
  and local volatility models (Heston, SABR, Dupire), interest-rate models
  (Vasicek, CIR, Hull–White, Black–Karasinski, LMM), bond/fixed-income
  pricing, credit risk (Merton structural, reduced form), market risk
  (VaR, ES, scenario analysis, stress testing, xVA, yield-curve construction)
  and the "Let's Be Rational" implied-volatility solver.
- **121 embedded parity tests** (`cargo test --lib`), with expected values
  generated by pure-float64 Python reference scripts (`scripts/gen_*.py`)
  against a shared deterministic RNG (`src/rng.rs` ↔ `scripts/refgen.py`,
  bit-exact normals) so Monte-Carlo pipelines match in float64.
- 21 runnable examples under `examples/`, mirroring the Python `examples/`.
- 4-backend benchmark harness (`bench/`): torch CPU, torch ROCm (HIP),
  Burn NdArray (CPU), Burn Wgpu/Vulkan — 10 shared workloads with check
  (parity) and bench (timing) modes; results in `bench/results.md`.
- Not converted (no portable numeric core): `calibration/*` optimizer
  harnesses, `utils/seq2seq_pde_solver.py`, and the GAN training loop (its
  forward-pass numeric core is ported in `src/gans.rs`).
